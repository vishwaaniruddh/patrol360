INSTALLATION & HARDWARE MANUAL

How to Setup This Project (Step-by-Step)

Complete instructions for vehicle wiring, Jetson Orin Nano OS flashing, software installation, and auto-start daemon configuration.

1 Vehicle Hardware & Power Wiring Hardware Phase

1. Power Supply: Connect vehicle battery (12V/24V) to an automotive isolated DC-DC step-down/regulator (19V 4.74A). Connect an ignition-sense wire to allow graceful Jetson shutdown.
2. PoE Network Switch: Mount an industrial 4-Port Gigabit 802.3af PoE switch inside the car. Plug in all 4 camera CAT6 cables.
3. Camera Positioning:

  • CAM 01 (Front): Roof center / windshield bracket, 15° downward angle, focused on 5m–30m vehicle plate zone.
  • CAM 02 (Rear): Above rear windshield/trunk, wide 90° for trailing traffic.
  • CAM 03 (Left): Left roof rack facing 45° left for sidewalk pedestrians and FRS face capture.
  • CAM 04 (Right): Right roof rack facing 45° right for junction crowd observation.
2 Jetson Orin Nano Flashing & System Dependencies Ubuntu 24.04

Flash the Jetson Orin Nano M.2 NVMe 512GB SSD with Ubuntu 24.04 / 22.04 LTS and run these terminal setup commands:

TERMINAL COMMANDS 
# 1. Update system packages
sudo apt update && sudo apt upgrade -y

# 2. Install Python, OpenCV, and video streaming tools
sudo apt install -y build-essential python3-pip python3-dev ffmpeg libopencv-dev \
  gstreamer1.0-tools gstreamer1.0-plugins-good gstreamer1.0-plugins-bad sqlite3

# 3. Lock Jetson in Max-N High Performance Mode
sudo nvpmodel -m 0
sudo jetson_clocks
3 Install Software Stack & Python Virtual Environment Software Phase
INSTALL DEPENDENCIES 
# 1. Create project directories
mkdir -p /opt/patrol360/{config,models,storage/captures,storage/videos,logs}
cd /opt/patrol360

# 2. Create python virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install PyTorch with CUDA & Server packages
pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install fastapi uvicorn httpx opencv-python sqlalchemy aiosqlite pydantic

5 Auto-Start Service on Vehicle Ignition (Systemd) Auto Recovery

Create /etc/systemd/system/patrol360.service:

SYSTEMD SERVICE FILE 
[Unit]
Description=Patrol360 Edge AI Daemon
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/patrol360
ExecStart=/opt/patrol360/venv/bin/python3 main.py --config /opt/patrol360/config/cameras.json
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Enable with: sudo systemctl daemon-reload && sudo systemctl enable --now patrol360.service
