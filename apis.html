Patrol360 REST APIs & Event Push Contracts

Standardized JSON payloads sent in real-time from the patrol car edge computer to the Police Command & Control Centre (ICCC).

📡 Store-and-Forward Offline Queue Policy

1. When Online: Events push directly via HTTP POST with a 2000ms timeout.
2. When Offline: If 4G/5G disconnects or HTTP returns non-200, the payload is inserted into SQLite central_api_dispatch_queue.
3. Automatic Recovery: A background daemon retries pending events using exponential backoff (1s, 2s, 5s, 15s, 60s) once cellular connectivity resumes.
